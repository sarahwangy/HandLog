门口只站着一个保安

登录环节最像一个只认一张脸的门禁。HandLog 不是要给所有人用的产品，而是自己给自己做的私人工具。

CODE · src/lib/auth.ts 

const ALLOWED_EMAIL = (process.env.ALLOWED_EMAIL ?? "").trim();

  // 登录时检查邮箱白名单
  async signIn({ user }) {
    return user.email === ALLOWED_EMAIL;
  },
PLAIN ENGLISH

先从环境变量里读出"允许登录的邮箱"，这个值不会被硬编码进代码里。

每次有人尝试登录，都会跑这段检查。

只有一件事被问：你的邮箱和白名单上那一个邮箱，是不是完全一样？

不一样，直接拒绝——没有"第二个用户"这回事。

💡
Key Insight

很多"登录系统"教程会讲注册、找回密码、多用户管理——但 HandLog 的登录只回答一个问题："你是不是那唯一一个人？"这提醒我们：需求决定架构复杂度，不是功能越全越好。

保安站在哪个岗位上？

门禁检查不是分散在每个页面里各查一次，而是在中间件这一个岗位上统一拦截。

CODE · src/middleware.ts 

  const token = await getToken({ req, secret: ... });
  if (!token) {
    // 未登录跳转到登录页，保留当前 URL 作为 callbackUrl
    const loginUrl = new URL("/en/login", req.url);
    loginUrl.searchParams.set("callbackUrl", req.url);
    return NextResponse.redirect(loginUrl);
  }
PLAIN ENGLISH

先问："这个访问者手里有没有登录凭证（token）？"

没有凭证的话……

就把他带去登录页，同时记下他原本想去哪儿。

这样登录完能自动送回他本来要去的地方。

没有凭证，一律不放行。

PLAIN ENGLISH

打个电话给 DALL-E 顾问，说"帮我画一张"。

用哪个型号的画笔（3 代模型）。

提示词是根据当天心情分数、地点动态拼出来的一段"日式手帐水彩画"风格描述。

只要一张，不用一次画一堆。

图片尺寸固定为 1024×1024。

让顾问直接把图片网址传回来，而不是传一大坨二进制数据。

⚠️
留意这里

DALL-E 这张"账单"比文字请求贵得多，所以它被设计成用户手动触发的可选功能，而不是每次生成复盘都自动画一张——这是一个成本上的克制。
