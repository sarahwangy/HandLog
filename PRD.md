> **HandLog** — Turn messy days into meaningful memories.
> An AI-powered journal that turns daily thoughts into structured reviews, visual handlogs, and auto-generated weekly/monthly reflections — all saved back to Notion.

---

## 1. Product Overview

### 1.1 One-line positioning
User speaks or types daily thoughts → AI extracts structure → generates a rich daily review + HandLog image → writes to Notion → auto-generates weekly/monthly reflection every Sunday / month-end.

### 1.2 Problem
- Hard to write structured reflections daily (friction)
- Raw journal entries stay raw — no extraction, no pattern recognition
- No visual output worth revisiting
- Weekly/monthly reviews require manual effort to compile

### 1.3 Core value
- **Low friction capture**: voice or text, open and go
- **Auto structure**: AI extracts people, places, events, books, health, emotions, finance, parenting, etc.
- **Visual output**: HandLog image (3 styles) auto-uploaded to Notion as cover
- **Auto reviews**: Weekly + monthly reflection generated by Vercel Cron, written back to Notion
- **Single source of truth**: everything lives in user's own Notion

## 4. AI Output Structure

### 4.1 Daily review (written to Notion as blocks)

Each section only appears if the journal entry contains relevant content.

```
📅 2026-05-26

【One-line insight】
In someone else's story of change, I saw the possibility of my own courage.

【People】(if mentioned)
- Jamie: talked about career transition, deciding to learn AI

【Places】(if mentioned)
- New coffee shop downtown — quiet, good for deep conversation

【Events】(if mentioned)
- 2-hour conversation about career direction

【Books】(if mentioned)
- Principles ch.3: radical transparency in decision-making

【Podcasts / Bloggers / Articles】(if mentioned)
- Podcast XYZ: careers in the AI era
- WeChat article: slow living

【Movies / TV Shows】(if mentioned)
- Show XYZ ep.3 — the family dynamics hit close to home

【Parenting】(if mentioned)
- Little one put on shoes alone for the first time — 18 months

【Health / Body】(if mentioned)
- Good sleep, walked 8000 steps, no issues

【Finance / Spending】(if mentioned)
- Bought a book ¥89 — worth it

【Learning / Skills】(if mentioned)
- Finally understood debounce in React

【Creative output】(if mentioned)
- Wrote a WeChat post, good response

【Emotions / Mental state】(if mentioned)
- Anxious in the afternoon, felt better after the conversation

【Today's review】
...100-200 word reflection paragraph...

【Next steps】
- [ ] Schedule another deep chat with Jamie
- [ ] Read Principles ch.4

【Energy distribution today】
Social connection 35% · Reading & growth 25% · Learning 20% · Parenting 15% · Health 5%

【Progress zones】
🟢 Breakthrough: First time truly understanding debounce
🟡 In practice: Daily journaling streak (5 days)
🔵 Planted seed: Starting to think about career direction

【Score】7.5 / 10
```

Progress zone definitions:
- 🟢 **Breakthrough** — clear cognitive leap or first-time achievement
- 🟡 **In practice** — habit or skill being reinforced
- 🔵 **Planted seed** — new direction noticed but not yet acted on

## 5. Completeness Check

Before running weekly/monthly review:

**Weekly:**
| Missing days | Action |
|---|---|
| 0 | ✅ Run immediately |
| 1–2 | ⚠️ Run with note: "X days missing, review based on available data" |
| ≥3 | 🚫 Enter waiting state |

**Waiting state:**
- Check daily at 22:00 CST whether user has filled in missing days
- Once missing ≤2 days → run the delayed review
- Notify user by email: "Still missing X days this week — fill them in and I'll generate your review 🌱"
- If not resolved by following Wednesday → mark as skipped, write "insufficient data" note to Notion

**Monthly:**
- Same logic, threshold: ≤20% of days missing (≈6 days)
- Deadline: 5th of next month

## 6. Notion Data Model

### 6.1 Main database (one row per day)

| Field | Type | Written by |
|---|---|---|
| Name | Title | AI (e.g. "5-26") |
| Daily summary | Text | AI |
| Labels | Multi-select | AI |
| Score | Number | AI (user can adjust) |
| One-line insight | Text | AI |
| Review | Long text (blocks) | AI — full structured review from §4.1 |
| Next steps | Text | AI |
| HandLog image | Files | Auto-uploaded PNG |
| Psychology note | Long text | AI |

### 6.2 Review summary page (separate Notion page)

Weekly and monthly reviews are appended as new blocks to a single Notion page. Each entry has a date heading so they stack chronologically.

### 6.3 Vercel KV schema

| Key | Value | TTL |
|---|---|---|
| `draft:{userId}:{date}` | Draft JSON | 7 days |
| `cache:notion:{userId}` | Notion metadata | 5 min |
| `pending_review:{userId}:{weekId}` | Pending review state | 30 days |

## 7. HandLog Image

- Generated with **Satori + sharp** (React component → SVG → PNG)
- 3 styles: **Minimal / Cute / Vintage**
- Content: date, keywords, one-line insight, score, next steps checklist, HandLog watermark
- Color theme based on dominant tag for the week
- Auto-uploaded to Notion as page cover / attachment
- High resolution (A5/A4 printable)

## 10. Cron Schedule

| Job | Schedule (UTC) | CST equivalent |
|---|---|---|
| Weekly review | `0 13 * * 0` | Sunday 21:00 |
| Monthly review | `0 13 28-31 * *` + code check "is tomorrow the 1st?" | Last day 21:00 |
| Retry pending | `0 14 * * *` | Daily 22:00 |

All routes protected by `CRON_SECRET` header.

## 11. Non-functional Requirements

- Mobile responsive (375px+)
- Notion token AES-256-GCM encrypted in KV
- API rate limit: 60 req/min per user
- AI response streaming (first token < 2s)
- HandLog image generation < 3s
- Voice: raw audio never stored (transcribe and discard)
